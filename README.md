# Argos Translate GUI (Mongolian Desktop Edition)

Desktop graphical user interface for [Argos Translate](https://github.com/Tsengel-de/argos-translate), with out-of-the-box support for Mongolian (Cyrillic) language translation models (`translate-en_mn` and `translate-mn_en`).

---

## Downloads for Desktop Users (No Coding Required)

Pre-built standalone installers and executables are available on the [Releases page](https://github.com/Tsengel-de/argos-translate-gui/releases):

- **Windows**: `ArgosTranslate-Windows-x64.exe` (Standalone executable, double-click to run)
- **macOS**: `ArgosTranslate-macOS.dmg` (Drag and drop into Applications)
- **Linux**: `ArgosTranslate-Linux-x86_64` (Standalone binary)

---

## Install via pip (For Developers)

```bash
pip install git+https://github.com/Tsengel-de/argos-translate.git
pip install git+https://github.com/Tsengel-de/argos-translate-gui.git

argos-translate-gui
```
